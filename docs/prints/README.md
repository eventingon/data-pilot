# Prints (evidências)

Coloque aqui as capturas de tela do app rodando. Sugestão de nomes citados no
README principal:

- `painel.png` — cards, filtro de categoria e gráfico de receita mensal;
- `chat.png` — uma pergunta respondida, de preferência com a legenda
  "Ferramentas usadas: ...".

Como capturar:

1. `streamlit run app.py`
2. Abra a aba **Painel**, ajuste o filtro e tire o print.
3. Abra a aba **Conversar**, pergunte algo como
   "Qual a receita média por cliente?" e tire o print da resposta.

Prints reais são a melhor evidência de que o app funciona no seu ambiente.
